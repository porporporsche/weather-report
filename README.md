# 天気と気圧

現在地（GPS）の天気・気圧・雨雲レーダーを1画面で見られる、1ファイルのWebページです。日本と世界の主要都市にも切り替えられます。APIキーもサーバーも要りません。

## できること

- **現在地を自動取得**：開くたびにGPSで現在地を取ります。30分以上たってから画面に戻ったときも、自動で更新します。
- **気圧**：今の値、3時間後の変化、8日間の気圧予報グラフ（4つの予報モデルを重ね描き）、日ごとの影響度（大・中・小）を表示します。
- **これから12時間＋雨雲レーダー**：12時間分の予報を6時間ずつ2行に並べ、その横に雨雲レーダーの地図を置いています。
  - 地図は直近1時間の実況と、その先の予報をアニメーションで再生できます。
  - 「拡大」を押すと地図を大きく表示します。
  - 「19:15ごろから雨」のような、この先2時間の雨の見通しも出します。
- **8日間の予報**：各日をタップすると、その日の1時間ごとの予報（天気・気温・降水確率・雨量・風・気圧）と、予報モデルごとの比較が開きます。今日・明日のカードにある「時間ごとの予報」ボタンからも開けます。
- **都市**：日本9都市・世界13都市にワンタップで切り替えられます。地名検索は日本語でも使えます。

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作ります（例: `weather`）。公開（Public）にしてください。無料プランでは非公開リポジトリから Pages を公開できません。
2. 「Add file → Upload files」で `index.html` と `README.md` をアップロードし、「Commit changes」を押します。
3. **Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main`・`/ (root)` にして **Save** を押します。
4. 1〜2分後に `https://<ユーザー名>.github.io/weather/` で開けるようになります。
5. スマホで開いて、位置情報の利用を「許可」します。共有メニューから「ホーム画面に追加」をすると、アプリのように起動できます。

更新するときは、新しい `index.html` を同じ名前でアップロードし直すだけです。

## データの出典

| 内容 | 出典 |
|---|---|
| 天気・気圧の予報 | [Open-Meteo](https://open-meteo.com/)（CC BY 4.0）。気象庁・ECMWF・NOAA GFS・DWD ICON のモデルを使用 |
| 雨雲レーダー（日本） | [気象庁 高解像度降水ナウキャスト](https://www.jma.go.jp/bosai/nowc/) |
| 雨雲レーダー（海外） | [RainViewer](https://www.rainviewer.com/) |
| 地図 | © OpenStreetMap contributors（APIキー不要） |
| 地名 | [BigDataCloud](https://www.bigdatacloud.com/)、Open-Meteo Geocoding |
| 地図の表示 | [Leaflet](https://leafletjs.com/) 1.9.4 |

Open-Meteo の無料枠は非商用・1日1万リクエストまでです。個人で使う分には十分足ります。
